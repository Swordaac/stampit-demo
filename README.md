# StampIt demo

Interactive, clickable demo of StampIt: digital stamp cards for local stores.

Live: https://swordaac.github.io/stampit-demo/

- Side-by-side owner and customer phones (desktop), full-screen app (phone)
- Direct links: `#owner/cafe`, `#customer/maya`, `#both/bakery/priya`
- All data is sample data saved in the viewer's browser; "Reset demo" restores it.
